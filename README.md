Todo Planner

A clean and responsive Todo Planner built with React, Vite, Tailwind CSS, Context API, and localStorage.

The application is designed to make daily tasks easier to organize, track, and complete through a simple, distraction-free interface.

✨ Features

Add new todos

Edit existing todos

Delete todos

Mark todos as completed or active

Persist todos with localStorage

Filter todos by All, Active, and Completed

Search todos

Sort todos

View total, active, and completed task counts

Clear completed todos

Responsive layout for desktop, tablet, and mobile

Light/Dark theme support

Clean and minimal UI

🛠️ Tech Stack

React — UI development

Vite — Development server and production build tool

Tailwind CSS — Styling and responsive design

Context API — Global Todo state management

localStorage — Persistent browser storage

Oxlint — JavaScript/React linting

🚀 Getting Started

1. Clone the repository

git clone https://github.com/Ajay-thakur01/Todo-.git

2. Navigate to the project

cd Todo-

3. Install dependencies

npm install

4. Start the development server

npm run dev

Vite will start the local development server. Open the URL shown in your terminal.

📦 Production Build

Create a production build with:

npm run build

Preview the production build locally with:

npm run preview

🔍 Linting

Run Oxlint with:

npm run lint

💾 Data Persistence

Todo data is stored in the browser using localStorage, allowing tasks to remain available after refreshing the page.

Because the data is stored locally in the browser, todos are specific to the current browser/device and are not synchronized with a backend server.
